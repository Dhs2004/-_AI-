# 星潮纪行 · Starfall Chronicle

原创 2D 群岛探索、潮灵收集与回合制对战 RPG。当前为开发中的 0.2 版本。

私人在线预览：<https://starfall-chronicle.seedagi.chatgpt.site>（需要使用站点所属账号登录）。

## 本机运行

在 macOS 上双击 `启动游戏.command`，或在项目目录执行：

```sh
npm run dev
```

然后访问 <http://127.0.0.1:4173>。无需安装 npm 依赖，服务器使用 Python 3 标准库。

## 操作

- WASD / 方向键移动，Shift 奔跑；点击地图可自动寻路。
- E / 空格与邻近人物、宝箱、素材和路标互动。
- P 队伍、B 背包、M 群岛地图、J 手记、L 图鉴；Esc 关闭菜单。
- 战斗中数字 1–4 对应当前菜单选项。守势恢复技能能量。
- 移动设备可使用屏幕方向键和互动按钮。

浏览器会自动保存当前旅程。设置里的“导出存档”用于备份、换设备或换访问地址。不同网址（例如 localhost 与 127.0.0.1）使用各自独立的存档。

## 当前实现

- 八章有结局的主线、八座岛与 48 张地图（16 张城镇/原野、32 层遗迹）。
- 24 段主线地区冒险、144 个阶段，包括 25 场对战、20 个顺序谜题、21 次人物选择与 8 次素材交付。
- 角色随任务移动，手记提供人物卡片、阶段时间线与下一站追踪；完成时展示记忆与物品奖励。
- 24 套符柱封门谜题、80 名遗迹训练师、80 个补给箱与 96 处线索和环境叙事。
- 16 个原创潮灵家族、48 种成长形态、九种属性。
- 捕获、进化、六人队伍、备用驿站、技能能量、护符、天气与异常状态。
- 药品、商店、素材拾取、合成、训练师、守灯人及通关后的星海试炼。
- 24 个委托、24 段选择型居民故事、48 个分支回应、八段营火谈话。
- 原创像素角色、月夜标题画面、八种专属战场、九种属性战斗特效；合成音乐和音效。
- 精细、均衡、流畅三档画质，实际 FPS 显示；共享精灵图集、地形缓存、菜单和后台暂停渲染。
- 本机存档、上一份备份、存档导入导出；每个完整战斗回合可恢复，未读主线和冒险回应保留。

## 开发与验证

```sh
npm run check
npm test
```

数据位于 `dist/js/data.js`、`dist/js/stories.js` 与 `dist/js/expedition-stories.js`；战斗和存档在 `engine.js`，地图在 `world.js`，素材在 `art.js`，界面在 `game.js`。

当前 40 项自动检查覆盖内容引用、地图碰撞与可达性、谜题封门、战斗结算/动画顺序、存档、剧情奖励和渲染缓存。实际 Chrome 试玩已验证新游戏、寻路、地图切换、完整训练师战斗（技能、复活、换人、胜利）、剧情选择与手记、刷新续玩、符柱保存，冒险阶段与奖励、未读主线的恢复，并检查了手机尺寸布局。

刷新时若战斗动作仍在播放，会恢复到上一完整回合。已结束的战斗奖励已写入旅程，不会重新恢复为可领奖的战斗。旧版已获得的碎片和灯印保留。

在这台 Mac 的 Chrome、DPR 2 / 2274×1200 渲染画布上，34 场景短测多数为 116–120 FPS，最低一次为 80 FPS。手机尺寸测试仍运行在此 Mac 上，不能代表手机硬件性能。0.2 新增内容后的 2400×1200 短测：户外场景 59–60 FPS、平均绘制 0.49–1.54 ms；全部 34 场景 52–60 FPS。不同轮次会受浏览器和屏幕状态影响。尚未完成人工全流程通关或长时间平衡验证。

这是 24 小时开发目标中的阶段版本。目标为分两天累计 16–24 小时游玩；当前内容时长尚未验证，不宣称达到商业长篇 RPG 的规模。后续开发进度见 `DEVELOPMENT.md`。
