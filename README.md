# 星潮纪行 · Starfall Chronicle

原创 2D 群岛探索、潮灵收集与回合制对战 RPG。当前为开发中的 0.10 版本。

私人在线预览：<https://starfall-chronicle.seedagi.chatgpt.site>（需要使用站点所属账号登录）。

## 本机运行

在 macOS 上双击 `启动游戏.command`，或在项目目录执行：

```sh
npm run dev
```

然后访问 <http://127.0.0.1:4173>。无需安装 npm 依赖，服务器使用 Python 3 标准库。

## 操作

- WASD / 方向键移动，Shift 奔跑；点击地图可自动寻路。
- E / 空格与邻近人物、宝箱、素材和路标互动。
- K 打开当前位置的随身航图，可筛选附近地点、预览步行路线并前往；方向键或菜单可停止，抵达后主动互动。
- P 队伍、B 背包、M 群岛地图、J 手记、L 图鉴；Esc 关闭菜单。
- 战斗中数字 1–4 对应当前菜单选项。守势恢复技能能量。顶部 1× / 2× 切换演出速度，“招式说明”和“战况回顾”帮助查看战斗细节。
- 移动设备可使用屏幕方向键和互动按钮。

浏览器会自动保存当前旅程。设置里的“导出存档”用于备份、换设备或换访问地址。不同网址（例如 localhost 与 127.0.0.1）使用各自独立的存档。

## 当前实现

- 八章有结局的主线、八座岛与 64 张地图（8 座城镇、24 个户外分区、32 层遗迹）。
- 24 段主线地区冒险、144 个阶段，包括 25 场对战、20 个顺序谜题、21 次人物选择与 8 次素材交付。
- 城镇、原野与遗迹的 64 张随身航图，按故事、补给、出口、切磋、见闻与机关筛选地点；路线遵循真实碰撞和封门，在可正确互动的位置停下，遇敌会中断。
- 户外分区具有独立地形、双向出口、48 处见闻和 48 个补给箱；地区航图显示道路、出口和当前任务。
- 角色随任务移动，手记提供人物卡片、阶段时间线与下一站追踪；完成时展示记忆与物品奖励。
- 24 套符柱封门谜题、80 名遗迹训练师、80 个补给箱与 96 处线索和环境叙事。
- 16 个原创潮灵家族、48 种成长形态、九种属性；每个家族有独立特性，进化后保留。
- 对手提前公布下一回合意图，能够守势和轮换；八位守灯人有不同战术，部分家族有跨属性技能组合。
- 血条按命中、恢复、反噬与持续伤害逐项变化，轮换和退场遵循实际行动顺序；可切换正常/双倍演出，回顾最近 80 条战斗记录。桌面技能卡显示完整说明，手机使用独立说明面板。
- 战斗状态卡可查看特性，显示护盾与蓄势；轮换时的技能克制提示针对即将入场的伙伴。
- 技能记忆可从已学招式中选择四招、互换顺序或恢复自动搭配；高等级伙伴可以重新携带跃击，手动选择会保留到升级和进化后。
- 按对手等级调整经验，全体参战者获得完整份额，替补享有共享经验和低等级追赶。
- 捕获、进化、六人队伍、备用驿站、技能能量、护符、天气与异常状态。
- 药品、商店、素材拾取、合成、训练师、守灯人及通关后的星海试炼。
- 商店按药品、缔约、护符和素材分类，支持 1 / 5 / 10 份购买；合成显示批量产量、材料需求与不足原因。
- 月息草与潮晶碎片可在商店补充；从此版本起，击败训练师后显示绿色勾选与“已切磋”，仍可再次挑战。
- 八台旧日仪器、八封群岛回信：折光镜、联动灯阵、一笔星图三类机关，保存中途状态，奖励仅发放一次；手记可重读，集齐并通关后有共同尾声。
- 十六种原创像素道具图标用于商店、背包、合成、护符和奖励界面；图标只在创建时绘制。
- 16 个家族的同行纪事，共 48 章、每章两个回应；第三章会呼应第二章的选择。按默契 8 / 24 / 48 与灯印进度开放，进化和备用驿站保留进度，已读内容可以重读。
- 四种故事纪念护符，在生命、攻击、防御和速度之间提供取舍；换装前显示完整属性变化，更换与取下时按比例调整生命。
- 营火恢复全队后，可读伙伴故事、听阿汐谈话或继续旅途；故事奖励仅发放一次。
- 24 个委托、24 段选择型居民故事、48 个分支回应、八段营火谈话。
- 原创像素角色、月夜标题画面、八种专属战场、九种属性战斗特效；合成音乐和音效。
- 精细、均衡、流畅三档画质，实际 FPS 显示；共享精灵图集、地形缓存、菜单和后台暂停渲染。
- 本机存档、上一份备份、存档导入导出；每个完整战斗回合可恢复，未读主线和冒险回应保留。

## 开发与验证

```sh
npm run check
npm test
```

数据位于 `dist/js/data.js`、`dist/js/stories.js` 与 `dist/js/expedition-stories.js`；战斗和存档在 `engine.js`，地图在 `world.js`，素材在 `art.js`，界面在 `game.js`。

当前 99 项自动检查覆盖内容引用、地图碰撞与可达性、谜题封门、战斗结算/动画顺序、存档、剧情奖励和渲染缓存。实际 Chrome 试玩已验证新游戏、寻路、地图切换、完整训练师战斗（技能、复活、换人、胜利）、剧情选择与手记、刷新续玩、符柱保存，冒险阶段与奖励、未读主线的恢复，并检查了手机尺寸布局。已验证户外分区往返、遗迹回程、分区刷新恢复、任务目的地地图及 390×844 窄屏航图。0.4 新增特性触发与恢复、行动预告存档、敌方守势和轮换目标、手机尺寸战斗预告验证。0.6 验证三类仪器解法、刷新续解、重读回信与一次奖励。0.7 验证技能选择与顺序、刷新和战斗续存、实战使用、低等级锁定与恢复自动搭配。0.8 验证逐项恢复/伤害、双倍演出、轮换与灼伤、回顾和刷新续战，并修复手机技能/六人轮换界面对生命值的遮挡。

0.9 验证三章伙伴故事、选择呼应、一次奖励、刷新重读、装备增减、穿脱后的生命比例及营火恢复与谈话返回；桌面和 390×844 阅读/装备布局已检查。

0.10 验证城镇护士路线、到达提示、遗迹封门阻挡、遇敌中断与回程出口，桌面并排地图和手机单栏布局已检查。地图仅在打开、选择地点、筛选或改变窗口大小时绘制；不加入场景动画循环。当前完整界面的短时观测出现约 60 与 116 FPS，不能当作持续保证。

刷新时若战斗动作仍在播放，会恢复到上一完整回合。已结束的战斗奖励已写入旅程，不会重新恢复为可领奖的战斗。旧版已获得的碎片和灯印保留。

在这台 Mac 的 Chrome、DPR 2 / 2400×1200 渲染画布上，0.3 的 24 个户外分区短测为 106–121 FPS，平均绘制 0.26–2.41 ms。此前连续切图曾出现最低 10 FPS 的短时下降；改为有明确容量上限、主动释放的地形缓存后，该次复测未复现。地形缓存保留两张户外地图时约 21 MiB。不同轮次仍会受浏览器和屏幕状态影响；这些数据不能代表手机硬件或长期保证。

0.4 的九种战斗特效复测时，机器处于电池低电量状态，实际为 29–30 FPS，平均绘制 0.41–1.20 ms。随后接通电源，0.5 在同一画布与九场景下复测为 105–120 FPS，平均绘制 0.16–0.85 ms。没有在两次测量之间改动渲染器，但不能仅据这两次短测确认原因或保证持续高帧率。

0.8 的九种战斗特效短测为 118–121 FPS，P95 帧间隔 8.8–9.3 ms，平均绘制 0.33–0.60 ms；同为 Chrome、2400×1200 / DPR 2。这是渲染器短测，不能代表整段游玩或手机硬件。

`node scripts/campaign-budget.mjs` 可复现经验预算：假定每段地区冒险战斗、每位遗迹训练师和每位首领各胜利一次，最终首领前主力约 51 级、替补约 49 级，首领起始 52 级。这是经验分配分析，不是实际战斗通关或游玩时长验证。已有存档的等级和经验保留。

`node scripts/combat-study.mjs` 运行真实战斗引擎的独立首领研究。四组条件各测试八位首领、每位 30 个种子，共 960 场：此轮无 180 回合仍未结束的样本。仅攻击的固定队伍在最终首领为 0/30；带辅助技能、可购买防御护符并按可选探索经验预算培养的队伍为 27/30。研究会提前恢复全队并分配 5 份药品、2 份净化道具，不模拟其获取；不能据此宣称完整旅程通关、玩家胜率或游玩时长。

`node scripts/campaign-study.mjs` 从真实初始队伍出发，连续携带经验、金钱与库存运行旅程研究；`node scripts/campaign-study.mjs --matrix` 输出四组条件、六个种子的完整 JSON 报告（本轮记录在 `qa/campaign-study-06.json`）。默认探索组、无野外拾取组、无可选居民故事组各有 6/6 到达结局；跳过全部可选训练师组为 2/6，另有一场达到 360 回合上限。追踪显示弱势回复策略会显著拖长战斗，同一受限局面改用攻击策略可结束，因此不将回合上限称为不可解死循环。

研究安排每岛八场野外遭遇，假定发现沿途补给、知道谜题答案，并允许野外任务间回诊所；遗迹内通过道具、败退或末层泉水恢复。新版回信奖励未计入。它验证了这些条件下的资源与战斗推进，不是人工通关、玩家胜率或时长验证。尚未完成人工全流程通关或长时间平衡验证。

从 0.6 起，阅读回信、解机关和其他游戏菜单的前台时间也计入旅程记录；打开设置或切到后台暂停计时。已保存的旧时间不作补算。

这是 24 小时开发目标中的阶段版本。目标为分两天累计 16–24 小时游玩；当前内容时长尚未验证，不宣称达到商业长篇 RPG 的规模。后续开发进度见 `DEVELOPMENT.md`。
