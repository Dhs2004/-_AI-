## 重新导出图片

1. 从**仓库根目录**启动独立 QA 服务器：

   ```bash
   python3 -m http.server 4174 --bind 127.0.0.1
   ```

2. 打开 `http://localhost:4174/qa/readme-capture.html`。此工具的“载入测试存档”会覆盖**这个地址与端口**的进度，请使用没有个人存档的独立端口。它不会改动 `localhost:4173`、`127.0.0.1:4173` 或公开游戏地址的存档。如果 4174 正在使用，请选择另一个独立端口。
3. 在“测试存档”中选择上表场景，点击“载入测试存档”，再在游戏中点击“继续旅程”。全新旅程可直接保留标题画面。
4. 操作游戏到需要展示的画面。输入图片名，选择“游戏主舞台”“完整游戏画面”或“当前菜单”；导出菜单时需要先打开对应菜单。
5. 点击“导出 2× PNG”，等待出现尺寸和下载链接后保存到本目录。浏览器窗口大小决定输出尺寸；生成后检查文字、布局与内容，再更新 README。

导出页使用 [html-to-image 1.11.13](../../qa/vendor/README.md)，MIT 许可证随库附带。它只用于 QA，不会被游戏的 `dist/` 页面加载，也无需新增 npm 运行依赖。字体先等待加载并嵌入导出结果；导出副本会保留当前界面中单行标签的换行状态。
