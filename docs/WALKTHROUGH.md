## 1. 从第一盏灯开始

1. 在标题页点击「启程」，填写称呼并选择初始潮灵。没有账号、联网对战或登录步骤。
2. 看完开场后按 **J** 打开手记，选择「没有灯的引航课」；到灯穗港的港口岸边找 **引航员 · 浮葵**。
3. 按 **K** 打开随身航图，选当前任务人物或调查点，预览路线后步行前往。自动寻路会遵守地图碰撞，遇敌会停下，到达后按 **E** 互动。
4. 一条地区冒险可能包含交谈、调查、谜题、对战、交付与选择。听完回应、完成最后一步，才会得到该条路线的记忆碎片。
5. 同一岛的三条地区冒险都完成后，前往第三个户外分区，从遗迹入口进入。前三层解符柱封门，第四层挑战守灯人。
6. 获得灯印并看完后续剧情，按 **M** 打开群岛航图，启程前往下一岛。已开放的岛可以往返。

**常见误会：** 手记中的「居民委托」和「这座岛的三份记忆」是不同内容。只交药草、做图鉴委托不会自动凑齐主线碎片。

### 开局选谁

| 初始伙伴 | 适合的玩法 | 开局补位建议 |
| --- | --- | --- |
| 芽芽狐 · 森 | 恢复、牵制，森攻可处理首岛卵石龟 | 补风铃雀对付森系，再找潮系伙伴 |
| 炭绒猫 · 焰 | 爆发、灼伤，打首岛苔角鹿顺手 | 首岛补露珠团或卵石龟，遇岩系及时换人 |
| 泡泡鳍 · 潮 | 耐久、控场，每次入场获得短暂护盾 | 补芽芽狐与风铃雀，避免只靠潮攻 |

三只都能开局。先培养 2–3 位属性互补的伙伴，逐步补齐六人队；捕获超过六只后，新伙伴会进入潮灵驿站。

### 出发前的补给

城镇诊所和营火可以免费恢复全队，遗迹第四层也有恢复点。把有限药品留给战斗中或离恢复点较远的时候。

- 前两岛可先备晨露药 6–10、净潮盐 2–3、回声种 2、星约石 5–10。
- 中后期把主力回复药换成月露药，按消耗补货；进入长战前建议备 8–12 份、净潮盐 3–5、回声种 3–4。
- 这些是宽松的备货建议，可以按已有资金调整。沿途宝箱、居民委托、地区冒险与伙伴故事也会补充资源。
- 失败后会回到城镇并恢复全队，损失星砂为当前星砂的 8% 向下取整，最多 150；已经保存的碎片、灯印和机关进度保留。

## 3. 回合制对战攻略

### 先看意图，再决定指令

敌方下一步会显示攻击、守势或轮换。对手会真正换人，你这回合的攻击可能打在新入场者身上；不要只看当前目标的弱点。用药与换人也会给对手行动机会，低血时再补救可能来不及。

能量上限为 **5**。通常「跃击」回复 1 点，「守势」回复 2 点并提供护盾。灯花兔家族的跃击回复 2 点，齿铃鼠家族的守势回复 3 点。不要每回合只点高消耗大招；低耗攻击、守势和爆发要交替使用。

普通护盾使攻击伤害降低 45%；石芽偶家族有护盾时降低 60%。面对长时间防守，可以带「碎潮断甲」破盾，或在安全回合恢复、蓄势，再集中进攻。

### 属性关系

以下以**招式属性 → 防守方属性**为准。未列出的组合为 ×1；本作没有照搬其他游戏的克制表。同属性招式另有 ×1.2 的伤害加成。

| 招式属性 | 效果较强 ×1.6 | 效果较弱 ×0.7 |
| --- | --- | --- |
| 森 | 潮、岩 | 焰、霜 |
| 焰 | 森、霜 | 潮、岩 |
| 潮 | 焰、岩 | 森、雷 |
| 雷 | 潮、风 | 岩 |
| 岩 | 雷、焰 | 潮、森 |
| 霜 | 森、风 | 焰、岩 |
| 影 | 辉 | — |
| 辉 | 影 | — |
| 风 | 森 | 雷、霜 |

辉与影互相克制，因此用辉系打影系也可能受到强烈反击；风对森有强效，森攻击风仍按普通倍率处理。不同方向请分别查表。

天气也会改变伤害：细雨使潮攻 ×1.25、焰攻 ×0.8；炽阳相反；飞雪强化霜攻、风沙强化岩攻、月雾强化影攻，各 ×1.2。

### 技能与成长节点

- **16 / 32 级**：两次进化，家族特性和同行故事保留。等级上限 65。
- 基础家族招式在 **1 / 9 / 18 / 27 级**开放；「跃击」最初即可使用。
- **12 级**：全家族可学习「留星一触」，并开放第四技能位置。
- **22 / 38 级**：各家族开放两种进阶战技。在队伍的「技能记忆」中主动选入，基础自动搭配不会替你加入它们。
- 每只最多携带四招。高等级自动搭配可能不再保留跃击，需要稳定能量时手动装回。
- 胜利与缔约会给队伍经验；实际出场者获得完整份额，未出场者也有共享与低等级追赶。轮换培养时仍要考虑挨打风险。

| 场面 | 可考虑的应对 |
| --- | --- |
| 对方护盾难以突破 | 卵石龟／熔砂蟹等家族 22 级可选「碎潮断甲」 |
| 对方蓄势、疾风或春芽 | 暮灯蛾／墨月狼等家族的「空白回音」，优先攻击并驱散这些增益 |
| 对方预告高耗大招 | 灯花兔／齿铃鼠等家族的「断潮音」，先手抽能可能迫使对方改用跃击 |
| 己方普遍带异常 | 灯盏花／星鳞蛇 22 级可选「晨光净域」，同时净化前排与替补 |
| 需要稳定恢复 | 芽芽狐／苔角鹿等家族的「春芽守候」；注意换下场会清除持续效果 |

「空白回音」不清除护盾；「晨光净域」不复活倒下伙伴。提速也不一定快过优先招式。请按游戏内招式说明区分。

### 六人队搭建思路

前期围绕初始伙伴，加风铃雀、卵石龟、露珠团等容易遇见的家族。镜湾可以补灯花兔；赤炉可补熔砂蟹、墨月狼或石芽偶；后面再补雪羽鸮、灯盏花、星鳞蛇。无需执着同一套六只。

一支后期参考队伍可以是：**泡泡鳍家族（潮）＋炭绒猫家族（焰）＋灯花兔家族（雷）＋卵石龟家族（岩）＋灯盏花家族（辉）＋墨月狼家族（影）**。初始伙伴不同可替换对应位置；重点是覆盖多种属性，同时至少有恢复、净化与低耗输出。

普通护符可在商店购买：炉火坠攻击 +12%，海螺护符防御 +15%，顺风羽速度 +15%，心灯吊坠生命 +15%。攻击手与承伤者按职责装备；换装在战斗结束后进行，穿脱护符不会免费恢复生命。

### 卡住长战怎么办

连续补血却没有减少对手人数，通常说明输出窗口太少。先查看对方下一招；在对手守势、恢复或不利轮换时找机会蓄势、破盾或更换属性。不要依靠反复刷新改写结算，完整回合会连同随机状态一起保存。

## 4. 缔约、生态与同行故事

野生对战才能缔约，训练师和首领的伙伴不能捕获。目标生命越低越容易成功，异常也有加成；辉光星约石优于普通星约石，最终概率仍有上限，不存在必中的保证。

推荐流程：准备星约石 → 12 级后选入「留星一触」 → 把目标压到低血 → 使用缔约石。留星一触本身不会击倒对手，但后续中毒、灼伤仍会使 1 HP 目标倒下，抓捕时尽量避开持续伤害。

## 8. 通关后的星海试航

主线结束后，在最后驿站找到「星海试炼」入口。先查看邀请里的阵容、天气和提示，到候场营地免费恢复，再挑战。每三阶是一段故事，完成第 24 阶有共同尾声；之后仍可继续 65 级远海挑战。

| 阶数 | 邀请篇章 | 对手基准等级 | 战术重点 |
| --- | --- | --- | --- |
| 1–3 | 第一班无灯渡船 | 52–53 | 以守势补充能量，再用廉价攻击维持航速。护盾不会替代持续进攻。 |
| 4–6 | 雨里没有湿透的信 | 54–55 | 借雨天强化潮属性攻击，在不利对局中轮换；入场潮衣帮助接住来信。 |
| 7–9 | 炉火边的第九把椅子 | 55–56 | 利用晴日与灼伤施加压力，短暂防御后继续进攻，避免把炉火耗在等待里。 |
| 10–12 | 把风交给下一双手 | 57–58 | 重视先手与属性轮换，用下一位伙伴的安全入场换取反击位置。 |
| 13–15 | 长夜的第二班岗 | 58–59 | 借雪幕与有限恢复撑过压力，再由下一位伙伴接班；会寻找防守后的反击。 |
| 16–18 | 借来的梦要怎样归还 | 60–61 | 利用入眠与中毒制造压力，以吸取维持节奏；轮换能够避开不利属性。 |
| 19–21 | 白昼也需要谢幕 | 61–62 | 用多种属性与快速轮换寻找舞台中央的位置；蓄势之后会尝试强力突破。 |
| 22–24 | 没有终点的归航 | 63–64 | 混合各地的轮换、恢复与压制战术，让每位伙伴都能承担一段航程。 |

表中是每场队伍的基准等级，个体以赛前阵容为准。失败后可以补给、改招、换护符再来；已完成关卡支持重赛，但首通纪念只发一次。打不动恢复型队伍时，请回看「长战怎么办」，不要每回合只做防守。

## 9. 分两天游玩的路线建议

| 时段 | 建议目标 |
| --- | --- |
| 第一天前半 | 眠潮与镜湾：熟悉三份记忆、缔约、技能和免费恢复，培养 3–4 位伙伴 |
| 第一天后半 | 赤炉与悬钟：补齐属性、学料理、收回信，尝试生态调查和水岸记录 |
| 第二天前半 | 白眠与苔梦：完成二次进化，调整四招组合，准备异常处理和破盾 |
| 第二天后半 | 曜都与归零：完成主线结局，再按兴趣做试航、图鉴、同行故事和水岸手册 |

这是内容安排建议，**不是已经实测的 16–24 小时通关时长**。阅读速度、探索范围、战斗配置与是否查答案都会影响实际用时；游戏没有强制等到第二天的时间锁。

## 10. 存档与常见卡关

| 问题 | 处理方法 |
| --- | --- |
| 找不到下一个任务人物 | J 查看当前阶段与地点；M 看户外分区；进入目标分区后 K 寻路。人物会随任务阶段移动 |
| 地牢入口不开 | 检查本岛三份记忆是否 3/3，居民委托不是主线碎片 |
| 地牢下一层走不过去 | 读石碑并把所有符柱调到对应目标；随身航图不会穿过未开的门 |
| 目标显示完成但剧情没接上 | 先关闭其他菜单，完成当前回应与奖励画面；再看手记下一站 |
| 技能已经到了等级却找不到 | 队伍 → 技能记忆，把进阶战技主动放进四个位置 |
| 料理做不了或不能继续上课 | 先到对应岛的城镇学会食谱，确认材料充足并结束当前战斗 |
| 水岸手册不计数 | 必须由这处钓线引来并在战斗中缔约成功；击败、放生与普通捕获不计 |
| 没有声音 | 点击右上角音符；浏览器通常需要一次用户操作才允许音频 |
| 动画不流畅 | 设置切换「均衡／流畅」画质、减少动态效果；战斗可选 2× 演出 |
| 换地址后看不到存档 | 官网、localhost、127.0.0.1、不同端口各自保存；从原地址导出，再到新地址导入 |
| 战斗播放中刷新回到上一回合 | 正常：存档以完整回合为单位，已经结算的奖励不会重复领取 |

建议每天结束前到设置「导出存档」，把 JSON 保存在自己的位置。进度保存在浏览器，不会同步到 GitHub；清理网站数据可能删除本地进度。加载失败时可在设置尝试上一份备份，导入时使用游戏导出的完整文件。
